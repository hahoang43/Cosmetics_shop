💬 LuLu Chatbot - Quick Start

Hướng dẫn nhanh để kích hoạt Gemini AI Chatbot trên Lumina Cosmetics

🎯 Giới Thiệu

LuLu là một chatbot AI thông minh được tích hợp trên website Lumina Cosmetics. Chatbot này sử dụng Google Gemini AI để trả lời câu hỏi của khách hàng về mỹ phẩm, chính sách cửa hàng, và nhiều thông tin hữu ích khác.

✨ Tính năng:

  • Chatbot luôn có sẵn ở góc dưới phải của mỗi trang
  • Lưu lịch sử chat giữa các lần visit
  • Phản hồi thông minh và tự nhiên từ AI
  • Hỗ trợ tiếng Việt hoàn toàn
  • Responsive trên desktop & mobile

📋 Yêu Cầu

  • Server PHP hỗ trợ cURL extension
  • Kết nối Internet ổn định
  • Gemini API key (miễn phí)
  • Trình duyệt hiện đại (Chrome, Firefox, Safari, Edge)

🚀 Hướng Dẫn Setup

1

Lấy Gemini API Key

Truy cập một trong các link sau:

  • Cách 1 (Dễ nhất): Google AI Studio - Chọn "Create API key"
  • Cách 2: Google Cloud Console - Tạo project và enable Generative Language API
💡 Tip: Google cung cấp API key miễn phí với giới hạn reasonable (60 requests/phút).
2

Cập Nhật API Key

Mở file config/gemini_config.php và thay thế:

define('GEMINI_API_KEY', 'YOUR_GEMINI_API_KEY');

bằng API key thực của bạn:

define('GEMINI_API_KEY', 'sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx');
⚠️ Lưu ý bảo mật: Không bao giờ commit API key lên GitHub hoặc chia sẻ công khai!
3

Kiểm Tra API Key

Truy cập:

http://yoursite.com/backend/test_gemini.php

Nhập API key và click "Test API" để kiểm tra kết nối.

✅ Nếu thành công, bạn sẽ thấy phản hồi từ Gemini
4

Hoàn Thành!

Truy cập bất kỳ trang nào trên website, bạn sẽ thấy button LuLu ở góc dưới phải.

Click vào để bắt đầu chat!

📁 Cấu Trúc File

File / Folder Mục Đích Ghi Chú
config/gemini_config.php Lưu API key & cài đặt QUAN TRỌNG: Bảo vệ file này
backend/gemini_chat.php API handler chính Xử lý requests từ chatbot
backend/test_gemini.php Tool test API key Xóa sau khi setup xong
includes/chatbot.php HTML component Include vào footer
assets/css/chatbot.css Styling chatbot Có thể tùy chỉnh màu sắc
assets/js/chatbot.js Logic chatbot Xử lý UI & logic

🎨 Tùy Chỉnh

Thay Đổi Tên Chatbot

Sửa trong config/gemini_config.php:

define('CHATBOT_NAME', 'LuLu'); // Thay thành tên khác

Thay Đổi Màu Sắc

Sửa trong assets/css/chatbot.css, tìm và thay thế:

#D4A373 /* Màu primary - Thay bằng màu khác */ #c2905f /* Màu hover */

Thay Đổi Vị Trí Button

Sửa trong assets/css/chatbot.css:

.chatbot-toggle { bottom: 20px; /* Khoảng cách từ dưới */ right: 20px; /* Khoảng cách từ phải */ }

Cập Nhật System Prompt

Để chatbot trả lời theo cách bạn muốn, sửa system_context trong backend/gemini_chat.php

🐛 Troubleshooting

Chatbot không xuất hiện

  • ✓ Xóa cache trình duyệt (Ctrl+Shift+Delete)
  • ✓ Mở DevTools (F12) kiểm tra Console có error không
  • ✓ Chắc chắn footer.php được include trên tất cả trang

Chat không hoạt động / Lỗi API

  • ✓ Kiểm tra API key trong config/gemini_config.php
  • ✓ Truy cập backend/test_gemini.php để test
  • ✓ Kiểm tra Network tab (F12 > Network) xem request đi đâu
  • ✓ Chắc chắn server hỗ trợ cURL extension

Bot trả lời sai hoặc không liên quan

  • ✓ Cập nhật system_context trong backend/gemini_chat.php
  • ✓ Tăng/giảm temperature parameter (0.0-1.0)
  • ✓ Kiểm tra lại prompt instructions
